## FeedTheBetterQuesting
This simple mod added a sidebar button on your inventory GUI to open the BetterQuesting GUI.  

Requires:
- _FTB Library (Legacy)_
- _BetterQuesting Unofficial_ (Compatibility with **official version** is unknown and **won't fix**)
